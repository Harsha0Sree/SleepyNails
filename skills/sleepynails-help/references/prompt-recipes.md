# Sleepynails prompt recipes

Copy and adapt any prompt below inside a repository built by an older model.

## 1. Complete generational revamp (default)

```text
/sleepynails revamp this entire codebase using your full capability. Do not change any user-facing functionality, routes, API payloads, or persisted schemas. Pin behavior first and prove nothing broke.
```

## 2. Frontend craft and UX elevation only

```text
/sleepynails run ui-craft-elevation on this app. Keep every existing feature, route, form validation, and data flow identical, and elevate the layout, typography, responsiveness, and accessibility.
```

## 3. Clean architecture and strict types

```text
/sleepynails run architecture-unification across src/. Eliminate duplicated state, God files, and loose any types while keeping all external contracts unchanged.
```

## 4. Measured performance overhaul

```text
/sleepynails run performance-overhaul. Profile real load, fix the main bottlenecks, and report before-vs-after median numbers with equivalence proof.
```

## 5. Production hardening

```text
/sleepynails run hardening-and-security across all API routes, auth checks, and boundary parsers without breaking valid requests.
```

## 6. Unattended overnight upgrade

```text
/sleepynails run overnight-upgrade on a new branch. Leave stacked verifiable commits, an upgrade-decisions.tsv trail, and adversarial verification ready for review in the morning.
```
